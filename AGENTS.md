# Website development

Make website changes under `site/` and use `npm run check` to produce a build. Review the diff and write a focused commit that describes the change, why it was made, and how it was verified.

Use the local Git identity `EDM.Audio <dev@edm.audio>` for new commits.

Use the existing release workflow for production. Keep deployment credentials and signed Android packages in their existing locations. Preview playback, consent, and downloads when a change touches them.
